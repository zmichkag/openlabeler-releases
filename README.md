# 🏷️ OpenLabeler

**Современный визуальный конструктор этикеток, «рентген» кодов «Честный ЗНАК» и компилятор промышленных языков печати (ZPL II, TSPL 2, CVPL).**

> 🌐 **Попробовать онлайн без регистрации и VPN:** [openlabeler.dev](https://openlabeler.dev)

---

## 🎯 Что такое OpenLabeler?

Это легковесный автономный инструмент для инженеров КИПиА, 1С-программистов, селлеров маркетплейсов и специалистов по маркировке. Он заменяет тяжелые проприетарные пакеты (BarTender, NiceLabel) и избавляет от необходимости вручную верстать команды принтеров строками.

* **Единый бинарный файл (~20 МБ):** не требует установки Windows-драйверов, баз данных, .NET или сторонних библиотек. Работает на Linux, Windows и macOS.
* **Разделение дизайна и данных:** вы рисуете макет в визуальном редакторе, привязываете переменные (`{{.DataMatrix}}`, `{{.Weight}}`, `{{.BatchID}}`) и получаете готовый шаблон для конвейера или 1С.
* **Нулевая нагрузка на сервер при работе в браузере:** рендеринг холста и генерация GS1 DataMatrix выполняются на стороне клиента.

## ✨ Возможности

### 1. Визуальный WYSIWYG-дизайнер
* **Точная физика печати:** работа в миллиметрах (`mm`) с автоматическим пересчетом в физические точки термоголовки (`dots`) под разрешения **203 DPI (8 dpmm)**, **300 DPI** и **600 DPI**.
* **Удобная верстка:** привязка к сетке (Snap-to-Grid 1 мм), точное позиционирование, управление слоями и мгновенное превью.
* **Поддержка штрихкодов:** GS1 DataMatrix (ECC 200), Code 128, EAN-13.

### 2. Встроенный «рентген» кодов маркировки («Честный ЗНАК» / GS1)
Вставьте сырую строку из сканера или выгрузки ГИС МТ — инспектор разберет код на составляющие:
* Подсветка Application Identifiers: `(01)` GTIN, `(21)` серийный номер, криптохвосты `(91/92)` и `(93)`.
* Контроль наличия и корректности непечатаемого разделителя `<GS>` / `FNC1` (`0x1D`), потеря которого чаще всего приводит к браку на кассах.

### 3. Поддержка промышленных и офисных принтеров
Единый макет транслируется в нативный код целевого оборудования:
* **ZPL II** — Zebra и совместимые принтеры (`^XA`, `^FO`, `^BX`, `^A0N`).
* **TSPL 2** — TSC, Godex, Атол, Mertech (`SIZE`, `DMATRIX`, `TEXT`).
* **CVPL** — промышленные термотрансферные маркираторы и аппликаторы **Carl Valentin** (прямой экспорт шаблонов для скоростных линий без использования тяжелого ПО).

## 🔌 Сценарии интеграции

### Для 1С (УТ, КА, ERP, Розница)
Забудьте о проблемах с GDI-рендерингом через табличные документы 1С и размытых штрихкодах:
1. Создайте шаблон в OpenLabeler и расставьте переменные (`{{.ItemName}}`, `{{.DataMatrix}}`).
2. Отправляйте JSON с данными из 1С по HTTP API и получайте готовый код принтера или PNG-превью для отображения прямо в форме документа.

### Для скоростных конвейеров (OpenMark / MES)
Экспортируйте скомпилированный ZPL / TSPL / CVPL с плейсхолдерами для подстановки переменных на лету в высокоскоростных системах сериализации и агрегации.

## 📦 Установка и запуск (из готовых сборок)

Готовые скомпилированные бинарные файлы доступны в разделе **[Releases](../../releases)**.

### Linux (Ubuntu / Debian / Astra Linux)
```bash
# Скачайте актуальный релиз
chmod +x openlabeler-linux-amd64
./openlabeler-linux-amd64 --addr=0.0.0.0:8080
```
Откройте в браузере `http://localhost:8080`.

### Windows
Запустите `openlabeler-windows-amd64.exe` из командной строки или настройте как фоновую службу. Веб-интерфейс и API сразу будут доступны локально.
